# Task Runner 面板

“任务灵体”管理面板，提供一个可以在线编排、编辑并运行异步卡片脚本的完整示例。界面分为三部分：左侧为运行队列、右侧为卡片库与编辑器、底部为执行日志。用户可以拖拽或点选卡片加入队列，选择单次、全部或 Endless 模式启动执行，并实时查看输出。

## 架构概览

- **后端**：FastAPI + asyncio 构建的任务调度服务，使用 `TaskRunner` 顺序执行队列。卡片脚本存储在 `data/cards.json` 中，由自定义 `CardRepository` 负责加载、校验与运行时编译。
- **前端**：基于 Jinja2 模版的原生 HTML/CSS/JS，支持拖拽、实时状态轮询以及内置的卡片编辑器，可直接在浏览器中创建、修改或删除脚本。
- **持久化**：所有卡片的名称、描述与 Python 源码（需实现 `async def run(log)`）都会保存到 `data/cards.json`，运行中改动会立即生效。

## 快速开始

```bash
# 安装依赖
python3 -m pip install -r requirements.txt

# 启动服务（默认 127.0.0.1:8000）
python3 -m uvicorn backend.main:app --reload
```

打开浏览器访问 <http://127.0.0.1:8000/> 即可使用控制面板。

## 主要功能

- **拖拽队列**：右侧卡片库可拖入左侧运行列表，也可通过卡片上的「加入运行」按钮添加。队列按照加入顺序展示，并显示执行状态。
- **运行控制**：提供“运行一个”、“运行全部”、“Endless 运行”（持续监听队列）和“停止”按钮，可随时清空输出日志。
- **卡片编辑器**：点击“管理卡片库”打开编辑面板，支持：
  - 浏览所有卡片的名称、ID 与描述；
  - 新建卡片（默认填入可运行模板）；
  - 编辑现有脚本并立即保存生效；
  - 删除卡片，同时从 JSON 存储中移除。
- **日志输出**：下方日志实时展示每个队列项的运行记录，并自动滚动到最新内容。

## 进一步扩展的方向

1. 为卡片脚本加入版本历史或草稿机制，方便回滚。
2. 使用 WebSocket 推送取代轮询，实现实时状态更新。
3. 将运行结果写入数据库，提供历史查询与检索功能。
